# Каркас системы управления · демонстрация

Интерактивный прототип для встречи с производителем красок и тары. Это каркас для обсуждения, а не согласованное ТЗ на внедрение и не замена 1С.

**Демонстрация · Данные условные · Интеграции не подключены.**

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev        # http://127.0.0.1:5173
```

Статическая сборка без сервера разработки:

```bash
npm run build      # результат в dist/
npm run preview
```

Проверка расчётов и сценария показа без браузера:

```bash
npm run check
```

## Сброс и сохранение

- Действия сохраняются в `localStorage` браузера и восстанавливаются после перезагрузки.
- Кнопка «Сбросить демонстрацию» в верхней панели (с подтверждением) возвращает исходный набор.
- Все даты считаются от фиксированной даты демонстрации **12.10.2026**, поэтому показ повторяем в любой день.

## Сценарий показа

Пошагово описан в приложении: «Инструкция и правила для согласования» внизу левого меню. Кратко:

1. Обзор директора → число задержанных отгрузок у «Государственных контрактов» → заказ З-102.
2. Этап, ответственный, история; «Поставить поручение» → роль исполнителя → результат → роль директора → подтвердить.
3. Заказ З-101: технолог подтверждает, начальник производства формирует задание и вносит выпуск по бумажному наряду, склад отдельно принимает, затем частичная отгрузка.
4. Просроченная задолженность → «Показать оплаты» у СФ-0412.
5. Обращение +998 93 555-10-20 (три пропущенных звонка) → назначить, перезвон, результат.
6. Поставка ПС-201 «Ксилол» → «Поручить поиск замены».
7. Вернуться на обзор — сводка изменилась.

Переключатель роли меняет видимые поля и действия. Он иллюстрирует рабочие места и не является авторизацией.

## Демонстрационный набор

`src/domain/seed.ts`: 2 предприятия, 3 направления («Пример структуры»), 3 цеха, 10 заказов, 6 клиентов, 6 обязательств и 4 оплаты, 11 звонков в 5 обращениях, 5 поставок, 7 поручений. Все имена, суммы и документы условные.

## Устройство

- `src/domain/types.ts` — единый набор сущностей, связи по идентификаторам.
- `src/domain/calc.ts` — все расчёты: сводка и раскрытые списки используют одни и те же функции отбора.
- `src/domain/actions.ts` — действия сценария с проверками (нельзя принять больше выпущенного, отгрузить больше принятого, повторное нажатие не создаёт дубль).
- `src/pages/` — экраны; `src/ui/` — общие таблицы, формы и элементы.

Выбор React/TypeScript для каркаса не определяет будущую платформу.

## Правила для согласования

Правила расчёта, принятые в каркасе, и вопросы, которые нужно подтвердить перед ТЗ на внедрение, перечислены в приложении на экране «Инструкция и правила для согласования» (`src/pages/Guide.tsx`).
